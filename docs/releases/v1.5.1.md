# SID Lab 1.5.1 — Apple Silicon Preview

A free, open-source SID synthesizer for Apple Silicon Macs, available as a standalone app and AUv2 instrument.

## Downloads

- **[Standalone app](https://github.com/hakanschon/sid-lab/releases/download/v1.5.1/SIDLab-Standalone-arm64.zip)** — play without a DAW.
- **[Audio Unit](https://github.com/hakanschon/sid-lab/releases/download/v1.5.1/SIDLab-AU-arm64.zip)** — load in GarageBand or another compatible AUv2 host.
- **[Complete source](https://github.com/hakanschon/sid-lab/releases/download/v1.5.1/SIDLab-source.tar.gz)** — includes the pinned JUCE and libresidfp sources, build scripts and original notices.
- **[SHA-256 checksums](https://github.com/hakanschon/sid-lab/releases/download/v1.5.1/SHA256SUMS.txt)** — verify the downloaded files.

## Preview status

**These binaries are ad hoc signed, not Developer ID signed or notarized by Apple. macOS may block downloaded builds.** Use the source-build instructions if a downloaded build is blocked; do not disable macOS security protections. This release is intended for early testing.

Apple Silicon / arm64 only. macOS 12 is the minimum build deployment target; the hosted workflow passed on macOS 15. No Intel, Windows, Linux, VST or AUv3 builds are included. Manual listening, physical-controller and host save/reopen checks remain separate from automated validation.

## Get started

**Standalone:** extract the ZIP and open `SID Lab.app`. Choose **Options → Audio/MIDI Settings**, select your output and enable your MIDI keyboard.

**GarageBand:** quit the host, extract the AU ZIP, and copy `SID Lab.component` to `~/Library/Audio/Plug-Ins/Components/`. Reopen GarageBand and choose **AU Instruments → SID Lab → SID Lab → Stereo**. Open SID Lab's own window to select sounds. Back up an existing component and export your sounds before replacing an earlier development build.

## Inside

- 104 original presets, including retro drum kits, disco sequences and synth-pop textures.
- MOS 6581 / CSG 8580 emulation, Classic mono and Enhanced polyphony.
- Full chip editing, seeded Randomize/Mutate and eight learnable MIDI knobs.
- Trace, Spectrum and Orbit displays; portable `.sidlab.json` sound files.
