# Reporting a security issue

For a vulnerability, use the repository's **Security → Report a vulnerability** feature when enabled. If private reporting is unavailable, open an issue requesting a private contact without posting exploit details or personal information. Maintainers should enable private vulnerability reporting when publishing the repository.

Include the affected SID Lab version, platform and reproduction details. Do not send credentials, personal recordings or private GarageBand projects. This is a community project without a guaranteed response time. Only the latest published source revision is actively maintained.
